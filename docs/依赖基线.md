# 依赖基线

> 基线：GTNH **2.9.0**（2026-10-31 正式发布）。
> 范围：本线只对 GTNH 官方正式版负责；2.9.1、2.10 等新正式版发布时，同步更新本文件并适配模组。
> 最后更新：2026-11-25

## 一、策略

- 只对 GTNH 正式版负责：当前基线 2.9.0；不承诺对快照版、魔改整合包、删改模组的组合兼容。
- 依赖一律硬依赖：功能需要的模组直接写进 `dependencies.gradle`，并在 `@Mod` / `mcmod.info` 里声明为必需依赖；不写反射探测、不写缺依赖降级分支。
- 只依赖当前功能真正用到的模组，不为「整包都有」预拉未使用的模组。
- 依赖版本统一从本文件取，随正式版升级一起更新。

## 四、升级流程（GTNH 发布新正式版时）

1. 从 `GT-New-Horizons-Modpack` 新版本标签的 README 解析 Modlist，更新 `docs/GTNH-<版本>-模组清单.md`。
2. 用新版本号替换本文件 §二 表格与 `dependencies.gradle` 中的依赖版本。
3. `gradlew build` 通过后进游戏回归。
4. 打新 tag（如 `0.0.2`）发布，并在 CHANGELOG 记一条。
