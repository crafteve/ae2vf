# 依赖基线

> 基线：GTNH **2.9.0**（2026-10-31 发布）。本线只对该版本负责。
> 最后更新：2026-11-25

## 一、策略

- 只对 GTNH 整包负责：本线只支持 GTNH 基线版本（本文件），不承诺跨包、跨版本兼容。
- 依赖一律硬依赖：功能需要的模组直接写进 `dependencies.gradle`，并声明为必需依赖；不写反射探测、不写缺依赖降级分支。
- 只依赖当前功能真正用到的模组，不为「整包都有」预拉未使用的模组。
- 依赖版本统一从本文件取，随整包基线升级一起更新。

## 四、更新方法

整包升级时，从 `GT-New-Horizons-Modpack` 对应版本标签的 README 的 Modlist 表重新解析，
同步更新本文件与 `docs/GTNH-2.9.0-模组清单.md`，再调整 `dependencies.gradle`。
