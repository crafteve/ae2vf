## 0. 为什么先做 P0

在写任何数据同步之前，有两个问题必须先量出来，否则后面全是返工：

1. **面板占屏比例**：781×480 是算出来的，真实观感只有进游戏才知道
2. **配方查看器要留多宽**：JEI/EMI/REI 在客户端左右两侧各占一块，猜不准

这两件事用一张底图就能回答，成本不到一百行代码。所以 P0 只做「能看」，不做「能用」。

## 1. 边界

**做**：可拉伸的面板底图、`/idf gui` 开屏、真实字体画的假数据、可现场调的留白常量。

**不做**：数据同步、交互、动画、真实规则编辑。

界面上除了关闭按钮，什么都点不动——这是刻意的，点了会动会让人误以为已经接上数据。

## 2. 怎么试

```
/idf gui
```

面板按屏幕居中。留白（每侧给配方查看器的宽度）默认 **48**，可以现场改：

```
-Didlefactory.gutter=64
```

加到 JVM 参数里（开发环境改 `build.gradle` 的 `runs.client.jvmArguments`，或直接在 IDE 的
运行配置里加）。改完重开游戏即可，不用重新编译。

**怎么判断留白够不够**：打开面板，看 JEI 的原料列表有没有压到面板边框上；压到了就把 gutter 调大。

## 3. 尺寸

面板 = 屏宽 − 2×留白（上限 900×540，下限 480×320），居中。右侧固定 170，左区吸收剩余宽度。

**右区为什么是 170**：物品网格 9×18 = 162，两侧各留 4 就贴着面板边框。之前设 196，
网格左右各空 17，看起来像「格子浮在面板中间」。

**tab 条在顶栏里**，不占主体高度——它就是顶栏的右端，宽度正好等于右区。这样右区从上到下是
搜索框 → 物品网格 → 合成 → 背包，没有一层单独的分隔条。

三种 GUI 缩放下的实测（窗口 2560×1368）：

| 缩放 | 逻辑画布 | 面板 | 左区 | 右区 | 列宽 | 行数 | 网格行 |
|---|---|---|---|---|---|---|---|
| 2 | 1280×684 | 900×540（撞上限） | 718 | 170 | 289 / 104 / 112 / 112 / 93 | 18 | 14 |
| 3 | 853×456 | 661×456 | 479 | 170 | 135 / 92 / 86 / 86 / 72 | 15 | 12 |
| 4 | 640×342 | 480×342 | 298 | 170 | 123 / 93 / 74（丢了输入/输出） | 10 | 6 |

顶栏是最先撑不住的地方：640 宽时标题、下拉、状态点、统计文字、关闭按钮加两个 tab 一行放不下。
处理办法是**统计文字优先让位**（放不下就不画），而不是让文字互相压。

**表格列会按宽度退化。** 五列的最小需求是 501（80+88+76+76+64），放不下就按优先级丢：

```
五列 机器/状态/输入/输出/速率
  ↓ 放不下
四列 机器/状态/输入/输出      （丢速率）
  ↓
三列 机器/状态/速率           （丢输入+输出这一对，它们只有一边没意义）
  ↓
两列 机器/状态
```

**绝不允许列被画到右区上面**——这是 P0 第一版踩过的坑：640 宽下面板只有 544，
而列宽写死，结果输出和速率两列直接盖到了仓库网格上。

### 怎么读那行日志

打开界面时会在 `logs/latest.log` 打一行：

```
Idle Factory UI: screen=853x456 guiScale=3.0 gutter=96 panel=661x456 left=453 right=196 rows=15 gridRows=11 columns=[119 91 83 83 69]
```

排尺寸问题只看这一行：`screen` 是逻辑画布（不是物理分辨率），`guiScale` 是当前缩放，
`columns` 是按「机器/状态/输入/输出/速率」五列的宽度，丢掉的列显示 `-`。

## 4. 贴图从哪来

**不是手画的。** 静态外观由脚本离线生成：

```
python tools/gui/gen_textures.py
  → src/main/resources/assets/idlefactory/textures/gui/*.png
```

| 贴图 | 尺寸 | 用法 |
|---|---|---|
| `panel.png` | 10×10，边框 3 | 面板底：外深、内亮、一层内凹斜边 |
| `slot.png` | 4×4，边框 1 | 凹槽格子，可拉伸到任意大小 |
| `button.png` | 6×6，边框 1 | 凸起按钮 |
| `field.png` | 4×4，边框 1 | 输入框 |
| `divider*.png` `header_bg.png` `row_alt.png` | 1×1 | 分隔线、表头底色、隔行底色，拉伸使用 |
| `io_panel.png` | 10×10，边框 3 | IO 展开详情底板：深钢灰板材 + 内凹 |
| `io_cell.png` `io_cell_hover.png` | 6×6，边框 1 | 规则单元格与悬停态 |
| `button_hover.png` | 6×6，边框 1 | 按钮悬停底 |
| `io_header.png` | 6×6，边框 1 | IO 段头：上/左亮边、下/右 1px 深阴影 |
| `chevron_right.png` `chevron_down.png` | 7×7 | 展开/收起箭头 |

Java 侧**只做 blit**：`NineSlice` 把九宫格切成九块贴到任意矩形，不画边框、不画斜边。
唯一「像画图」的地方是用 1×1 贴图拉伸填充——那也是一次 blit。

这样做的好处：渲染代码简单、细节（内凹阴影、斜边）交给生成脚本、换主题只改调色板重新生成，
不用在 Java 里复刻一遍美术。

**色值必须两边一致**：`GuiTheme.AE2` 里的常量 ↔ `tools/gui/gen_textures.py` 顶部的调色板。
改色只改一边会造成贴图和文字脱节，而脱节在截图里看不出来。

## 5. 文件

```
tools/gui/gen_textures.py                     贴图生成脚本（改色改形状从这里发起）
tools/gui/preview_layout.py                   离线预览：按 3 种 GUI 缩放合成布局图
docs/ui/mockup-v1.*, mockup-v2.*              设计稿（v2 是定稿）
docs/ui/P0.md                                 本文
src/main/java/.../client/screen/FactoryScreen.java    骨架绘制
src/main/java/.../client/screen/FactoryLayout.java    全部几何，一处算完
src/main/java/.../client/screen/IoDetailRender.java   机器行展开详情：排版/绘制/命中
src/main/java/.../client/screen/FactoryLabels.java    左表与展开详情共用的文案/图标
src/main/java/.../client/screen/DemoRows.java         假数据（P1 删）
src/main/java/.../client/widget/NineSlice.java        九宫格 blit
src/main/java/.../client/widget/GuiTextures.java      贴图 id 与边框宽度
```

两个脚本都依赖 Pillow，都不联网：

```bash
python tools/gui/gen_textures.py        # 重新生成贴图
python tools/gui/preview_layout.py 96   # 参数是留白，输出到 .tmp/mockup/
```

**`preview_layout.py` 抄了一份布局常量**，改 `FactoryLayout.java` 时要同步，否则图会骗人。
它的用途只有一个：在开游戏之前发现「列画到右区上」这类几何错误——P0 第一版就是靠它抓出来的。

## 6. P0 顺手清掉的东西

改成指令打开界面之后，这一整条链退场了：

| 删掉 | 原因 |
|---|---|
| `TerminalItem` + 物品注册 + 创造模式标签 | 没有物品了 |
| `ModAttachments`（玩家附件） | 只服务「装备奇点」 |
| `SingularityInteractionHandler` / `SingularityUnequipHandler` | 同上 |
| `UnequipSingularityC2S` / `StorageSnapshotS2C` | 随上面一起没了 |
| `Ae2StorageView` / `ClientPacketHandler` / `ItemGrid` | 被新链路取代 |
| 终端模型与贴图 | 物品没了 |

净效果：「打不开界面」从三条可能（没物品、没奇点、网络不对）降到一条（没执行命令）。
