# UI · P1：产线菜单、机器拖拽与 IO 卡片编辑

> 状态：已接入界面，等待游戏内验收
> 关联：[P0.md](P0.md)、[DECISIONS.md](../DECISIONS.md)、[README.md](../../README.md)

## 1. 能力

`/idf gui` 内可以完成：

1. **新建产线**：顶栏产线下拉底部 `+ 新建产线`。
2. **重命名 / 删除 / 启动 / 暂停**：每行右侧 `>` 打开二级菜单。
   - 重命名只改名字，UUID 不变；同一浮层也用于新建。
   - 删除会先弹确认；机器会失去引用，规则一起移除。
3. **机器加入 / 移动**：在右侧「机器」tab 按住左键拖一台机器，放到左表末尾的「新增机器」空槽。
   - 机器原本在别的产线时按“移动”处理，保留原 IO 组和规则。
4. **机器移出**：在左表机器列按住左键，拖回右侧「机器」tab 的机器库网格。
   - 移出会移除该机器的 IO 组和规则；回收站清理逻辑与指令一致。
5. **IO 规则新增**：从右侧「仓库」tab 按住左键拖一个资源，放到：
   - 输入/输出紧凑列末尾的 `+` 空槽；或
   - 展开 IO 面板里输入/输出段末尾的「拖入资源」空卡。
6. **IO 规则编辑**：展开机器后，每张配置卡上：
   - 第二行左侧的面按钮显示当前面（`任 / 上 / 下 / 北 / 南 / 东 / 西`），左键切到下一个面、右键切回上一个面；
   - 面按钮右侧的黄色匹配按钮 `模 / 精`：物品可在模糊/精确间切换；带组件物品切到模糊时按注册名匹配所有变体；流体/FE 不显示；
   - 卡片空白处按住左键拖回「仓库」tab 的仓库网格删除；界面不再提供 `x`。
7. **IO 面板滚动**：展开区内容超过可见高度时，在展开面板上滚轮滚动。

## 3. 重要行为说明

- **仓库格点击改为“松开时执行”**：因为按下后要先判断是普通存取还是拖到 IO 空卡。单击仓库格的存取行为不变，只是生效时机从按下变成松开。
- **机器库卡片单击不再有任何动作**；必须拖动。
- **拖拽阈值 4px**：小于阈值视为单击；仓库格单击仍执行原存取手势。
- **资源拖拽来源只有仓库格**（玩家背包暂不作为拖拽源，避免破坏原版背包点击）。
- **移动机器保留规则**：把机器从 A 线拖到 B 线时，原 `IoGroup` 整体移动，组 id 和规则不变。
- **UI 新增规则的默认匹配 = 精确**（组件来自放入的资源）；指令的旧默认仍是无组件物品模糊。黄色按钮会显示当前模式；带组件物品也可以切到模糊，表示按注册名匹配所有变体。
- **卡片恢复 26px 紧凑样式**：第一行槽位、名称、右对齐速率；第二行面按钮、匹配按钮、状态。短名字两列、各占半行；长名字独占整行。空卡与规则卡使用同一槽位和高度。
- **顶栏状态描述当前产线**：运行中绿色、已暂停红色、睡眠灰色「睡眠 Ns」；仓库是否在线仍由右侧「仓库 在线/离线」单独表达。
- **化学品规则不支持**：服务端拒绝；仓库里的化学品格拖到 IO 空卡不会生成规则。
- **每侧最多 16 条**；到上限后空槽/空卡仍显示，但服务端会拒绝新增。

## 4. 限制

- 产线名 1–32 字符，不能含空白/控制字符；`rename` 等指令保留字不可用。
- 最多 64 条产线；下拉列表可滚动。
- 一台机器只能属于一条产线。
- 规则数量固定“塞满”，界面不提供数量上限编辑。
- 面/匹配都按资源 key 原地更新；资源 key 不变。
- 化学品、主动模式（pattern/CPU）未接入。

## 5. 网络与存档

- `PROTOCOL_VERSION` 升到 `12`；旧客户端会被拒绝连接。
- 新增包：
  - `FactoryLineActionC2S`：新建/重命名/删除/启动/暂停/放机器/移出机器；
  - `FactoryRuleActionC2S`：新增/更新面或匹配/删除规则；
  - `FactoryEditFeedbackS2C`：界面内反馈。
- 快照 `FactoryTableS2C` 增加 `lines`、每台机器的 `lineIds`，以及每条产线的 `sleeping` / `sleepRemainingTicks`。
- **不改存档 NBT**：产线名、机器归属、规则本来就已落盘；睡眠只是运行时状态。

## 7. 验收清单

1. 新建产线：下拉底部新建 → 自动选中；空表出现“新增机器”行。
2. 重名/保留字/空格/超长：命名浮层内报错，保持打开。
3. 二级菜单重命名：预填原名；保存后顶栏/下拉/机器行文案更新，UUID 与机器不变；`/idf line <shortId> info` 仍指向同一条。
4. 启动/暂停：顶栏绿「运行中」/ 红「已暂停」；下拉状态灯同步；`/idf line` 与 `diag` 一致。
5. 静置到睡眠：顶栏灰「睡眠 Ns」并每秒递减；下拉状态灯灰色；唤醒后恢复「运行中」。
6. 仓库绑定/解绑：右侧「仓库 在线/离线」变化，不影响产线状态文字。
7. 删除：确认后产线消失；回收站清理提示（如适用）。
8. 机器库拖一台到新增行：机器行出现，末尾继续补空行。
9. 选中 B 线，把 A 线机器拖到 B：移动成功且规则保留。
10. 把当前线机器拖回机器库：当前实现无二次确认，移出即生效；回收站清理按指令逻辑。
11. 从仓库拖铁锭到输入空槽：配置卡出现；`/idf line <线> manage <机器> info` 一致。
12. 面按钮：左键正向、右键反向循环七个面；面值落盘，执行按面生效。
13. 点黄色匹配：物品模糊/精确切换（含带组件物品）；流体/FE 无按钮。
14. 卡片：26px；短名两列各占半行，长名整行；空卡与规则卡槽位、高度一致；无 `x`。
15. 拖回仓库删除规则：卡片消失，紧凑列同步。
16. 加满 16 条：服务端拒绝第 17 条。
17. 展开区滚轮：能滚到段末空卡。
18. 产线下拉、二级菜单、命名/确认浮层压在表格物品上：无图标穿透。
19. 重启服务端/重进世界：产线名、归属、规则、面、模式保留。
20. 旧客户端连接被拒（协议 12）。
