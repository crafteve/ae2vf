设计备注 · v2 的取舍

  1. 边是逻辑依赖，不是管道。从源卡片右侧的输出锚点到目标卡片左侧的输入锚点，细虚线；目标在左侧时从卡片上方绕行，避免线穿过卡片。
  2. 折叠 96 / 展开 260。折叠态只保留「入 / 催 / 出」计数，展开才列端口；同一时间只展开一张，避免多个浮层互相遮挡。
  3. 积压 / 缺料用「当前/上限」角标。折叠态在右下角显示库存与目标存量的比值，展开态每行端口也带 cur/max，两者格式呼应；悬停给出文字解释，不只靠颜色。
  4. 拖拽用 4px 阈值区分点击与拖动。16px 吸附，拖动中只重绘边，松手才整体重渲染，避免卡片闪烁。
  5. GT 组装机压测展开态。5 输入 + 1 催化 + 1 输出，260px 刚好容纳 7 行端口 + 目标存量 + 进度。
