# 放置工厂 GUI 设计（讨论记录）

> 状态：讨论中（2026-10-24 起）
> 关联：[ARCHITECTURE.md](ARCHITECTURE.md)、[DECISIONS.md](DECISIONS.md)

## 0. 定性：这是编辑器，不是容器界面

原版 MC 的 GUI 模型是「容器 + 槽位」。放置工厂的 GUI 是「工作台」：

- 一块**工作区**：被动产线是画布，主动产线是表格
- 一条**机器栏**：所有已接入的机器
- 一条**存储栏**：ME 库存 + JEI 全物品 + 背包
- 少量**真实槽位**：终端的量子纠缠奇点

物品在这个界面里有三种角色，不能混：

| 用途 | 形态 | 是否需要真 Slot |
|---|---|---|
| 终端绑定槽 | 量子纠缠奇点 | 是（真实存储） |
| 过滤槽 | 拖物品进去 = 设置输入/输出 | 否（幽灵槽） |
| 存储/背包 | 浏览、搜索、拖出 | 否（列表 + 槽位控件） |

## 1. 整体布局

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：产线切换  [被动|主动]        [奇点] [⚙] [×]         │
├──────────┬──────────────────────────────┬────────────────┤
│ 机器栏    │ 工作区                        │ 存储            │
│          │                              │  ├ ME 库存     │
│ 已接入    │  被动：画布（正交连线）         │  ├ 全部物品    │
│ 未编组    │  主动：表格                   │  └ 搜索        │
│ 搜索…    │                              ├────────────────┤
│          │                              │ 背包            │
│          │                              │ 星标 / 快捷栏   │
└──────────┴──────────────────────────────┴────────────────┘
```

### 1.1 顶栏

- 产线切换（下拉或 Tab）
- 模式切换：被动 / 主动
- 奇点绑定槽
- 设置、关闭

### 1.2 机器栏（左）

- 已接入但未编组的机器
- 按产线分组
- 搜索框
- 拖拽到工作区 = 加入当前产线

### 1.3 工作区（中）

- **被动产线**：每个产线一张独立画布，新建画布 = 新建产线
- **主动产线**：一张表格

### 1.4 存储栏（右）

- 两种模式共用同一个列表控件和搜索框：
  - **ME 库存**：网络里实际有的物品
  - **全部物品**：JEI 的全量注册表
- 鼠标悬停 → R / U → 在当前 UI 上层弹配方浮层，ESC 返回
- 背包单独一栏（星标 + 快捷栏），与存储视觉相连、逻辑隔离

## 2. 被动产线：画布

### 2.1 节点卡片

每个节点是一张 180×96 的卡片，**配置与当前状态同时显示**：

```
┌──────────────────┐
│ ▣ 熔炉 #3      ▶ │  ← 图标 + 名称 + 朝向
│ ┌──┐   ┌──┐      │
│ │矿石│ → │铁锭│   │  ← 输入（配置）→ 输出（配置）
│ 12/16   4/8      │  ← 当前数量 / 配置上限
│ ████████░░ 60%   │  ← 进度
└──────────────────┘
```

- 槽位同时表达两层：**配置**（铁矿石）和**当前**（12/16）
- 状态色边框：运行青 / 缺料琥珀 / 停机红 / 离线灰
- 朝向只用于视觉识别，不承载逻辑；输入面不显示（物流是虚拟的，物理面无意义）

### 2.2 连线

- **只用正交折线**：横 → 竖 → 横，转弯半径 4px
- 不做贝塞尔、不做随机弯曲
- 交叉处用 2px 跳线缺口
- 线宽 2px，按物品颜色着色（可选）

### 2.3 表格视图（诊断，可编辑）

被动产线除了画布，还有一张表格视图，顶栏 `[图 | 表]` 切换：

| 机器 | 输入 | 输出 | 状态 | 吞吐 |
|---|---|---|---|---|
| A 熔炉 | 铁矿石 2/s | 铁锭 2/s | 运行 | 2.0/s |
| B 合金炉 | 铁锭 2/s · 煤 1/s | 钢锭 1/s | 运行 | 1.0/s |

- **可编辑**：点击单元格改配置（物品、速率）
- 表格负责排序、筛选、批量诊断；画布负责拓扑和布局
- 两张视图共享同一份数据，选中状态联动（点行 → 节点高亮，反之亦然）
- 边表不做：它和画布功能重叠，两套编辑入口会让玩家不知道改哪个

## 3. 主动产线：表格

主动产线的机器不配置 IO，由 AE2 CPU 调度，玩家关心的是「订单和产能」，所以用表格：

| 机器 | 绑定的 pattern | 状态 | 队列 | 实测吞吐 |
|---|---|---|---|---|
| 熔炉 #1 | 铁锭 ×1 | 运行 | 3 | 2.0/s |
| 压板机 #2 | 钢板 ×1 | 缺料 | 0 | 0/s |

列可排序、可筛选、可批量操作。

## 4. 机器展示（讨论中）

机器有自己的 GUI（进度、槽位、能量、IO 面），在我们界面里有三种处理方式：

| 方式 | 做法 | 评价 |
|---|---|---|
| 叠层 | 把对方 GUI 渲染进画布 | 技术债大，破坏整齐，不推荐 |
| 切换 | 右键「打开机器」，打开原生 GUI | 简单，但离开工作区 |
| 代展 | 读属性，用自己的控件重画 | 主方案，覆盖率取决于适配 |

倾向：**卡片代展 + 右键切换原生 GUI**。

## 5. 待定

1. 进度条读不到时，是否用「输入减少 / 输出增加」推算
2. 朝向是否作为卡片常驻信息（输入面已决定不显示）
3. 正交连线是否加「总线模式」
4. 画布缩放范围与平移方式
5. 表格编辑的范围：只改速率/物品，还是也能增删机器
