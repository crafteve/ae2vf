## 四、聚焦小块（Gallery 说明栏用）

`fragments/` 下是从整图里切出的小块，配合一句图注，适合放在 Gallery 的说明栏或描述里做"细节特写"。
它们不是独立 Gallery 图，别单独上传。

## 五、还缺的两张怎么拍

只差一张：**黄色高亮**。手持绑定杖、准星对准机器，让机器出现黄色描边后 F2。拍好放到本目录、命名 `01-wand.png` 即可。

## 六、通用要求

- 分辨率：2560×1334（当前截图规格），或至少 1920×1080；
- 语言：保持中文即可（当前这批是中文 UI；以后要英文页再整批重拍）；
- 关掉 F3 的 Dev Mode，鼠标移出列表，避免 tooltip 遮挡；
- 文件名固定用上表里的名字，覆盖同名文件即可，脚本与文案都按名引用。
