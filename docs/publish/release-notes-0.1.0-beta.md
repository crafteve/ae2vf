# 0.1.0-beta 发布说明

首个公开测试版，上传 jar 时粘进 Changelog 栏（格式选 Markdown）。

```markdown
首个公开测试版 / First public beta

**新增**
- 机器绑定杖：右键接入 / 断开，蹲下批量提交，同类型机器可连锁接入
- 被动 IO 终端：精确与模糊匹配、指定面、按优先级搬运，列表与磁贴两种视图
- 节点终端：节点状态、命名、阻挡开关、倍率与派单方式
- 主动合成：虚拟样板供应器，样板广告给 AE2 CPU，产物自动扫回网络
- 资源类型覆盖物品与流体；FE 需安装 Applied Flux

**要求**
- Minecraft 1.21.1 / NeoForge 21.1.x
- Applied Energistics 2 19.2.10 或更新（必需）
- Applied Flux、JEI 可选

**说明**
- 测试版：接口与平衡可能调整，遇到搬运异常或崩溃请附 logs/latest.log 反馈
```
