# 描述写作逻辑（源自宣传片解说顺序）

宣传片的叙事顺序是：

1. **钩子**：假如你的 AE 工厂不需要输入输出总线和样板供应器方块；
2. **三步上手**：绑定杖接入 → 终端里改名 / 阻挡 / 倍率 → 机器跑起来；
3. **主动合成**：虚空把 CPU 里的原料送进机器，倍率按机器容量算；
4. **被动规则**：搜索或拖拽建规则，配好烧结铁矿后熔炉正常燃烧；
5. **边界情况**：仓库是绑定杖绑定的 ME 网络；速率受机器容量限制；放错机器会被认出来；失联可以定位修复。

写文案时保持这个顺序，不要按"功能清单"罗列。原因：

- 读者第一眼要的是"这东西能帮我少做什么"，不是功能表；
- 三步上手放在功能之前，读者脑子里先有操作路径，后面讲机制才不悬空；
- 主动合成放前面，因为它是"看不出怎么实现"的亮点；被动规则放后面，因为它更接近常识；
- 边界情况放最后，回答"会不会把我机器搞坏"这类顾虑。

每段配一张图，图的顺序与段落一一对应（见 `screenshots/README.md`）。
