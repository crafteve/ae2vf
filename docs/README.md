## 怎么判断一份文档是不是过时

三条快速判据：

1. 它提到 `core/graph`、`FactoryNode`、`PortRef`、`ItemNode`、`MachineIo` → 过时
2. 它提到 `/idf` 聊天指令、产线对象（Line）、第一版工作台 → 过时（ADR-039 之后入口只有两个终端物品）
3. 它把界面描述成「库存 + 机器列表 + 画布」→ 过时

现行约束的入口只有两处：[AGENTS.md](../AGENTS.md) 与 [DECISIONS.md](DECISIONS.md)；
界面风格与几何约束在 AGENTS §3.2，状态与排序口径在 ADR-040 / ADR-041。
