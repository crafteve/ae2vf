## 【Agent 建议·未确认】

### 分层继承

- **终端物品继承 `WirelessTerminalItem`**：白拿充能、无线链接、升级槽、热键、tooltip。
- **host 继承 `WirelessTerminalMenuHost`**：白拿链接状态、供电、`getActionableNode`。
- **菜单与屏幕自己写**：`AEBaseMenu` + `AEBaseScreen` + `WidgetContainer`，控件用 AE 的（`AETextField` / `Scrollbar` / `TabButton` / `Blitter` / `AEKeyRendering`）。
- **不要继承 `MEStorageMenu` / `MEStorageScreen`**：它们把「AEKey 库存 + Repo 网格」写死在构造器和 `init()` 里，搜索框 private、`Repo` 只吃 `AEKey`、服务端每 tick 全量同步库存。我们的数据是机器列表，背上再挖掉不划算。

### 三个坑

1. **host 类型不匹配会导致终端静默打不开**（无异常、无日志）。`MenuTypeBuilder.create(MyMenu::new, MyHost.class)` 声明的 host 类型必须与 `getMenuHost()` 实际返回类型一致。
2. **`MenuTypeBuilder.build()` 会把注册塞进 AE2 自己的初始化队列**，附属在 AE2 init 之后调用就永远注册不上。必须用 `buildUnregistered(...)` + 自己的 `DeferredRegister`；`buildUnregistered` 已顺手做了 `MenuOpener.addOpener`。
3. **样式 JSON 的命名空间写死 `ae2:`**，附属无法加载自己命名空间的样式。出路：复用 AE2 现成终端样式（零资源起步），或把 JSON 放进 `assets/ae2/screens/`。

### 其它约束

- `SlotSemantic` 是 record，可以自定义并 `SlotSemantics.register(...)`；但**必须用注册返回的实例**，`new` 出来的查不到。
- 没写进样式 JSON 的语义槽不会被自动定位，要在 `init()` 里手动设坐标。
- 槽位列表在构造时固定，运行期只能隐藏不能增删；「切机器换一套配置槽」要让槽背后的 `InternalInventory` 做视图重定向。
- `@GuiSync` 不支持 `List`，机器列表要用自定义 payload 同步，`@GuiSync` 只放选中索引、视图枚举这类标量。
- 物品必须自己注册 `GridLinkables.register(myItem, WirelessTerminalItem.LINKABLE_HANDLER)` 和 `HotkeyActions`，否则无线接入点不认、热键打不开。

### 验证顺序

1. 只覆盖 `getMenuType()`，用现成 host，确认能打开一个空菜单。
2. 再加 `getMenuHost()` 自定义 host。
3. 最后做屏幕。

这样「打不开」的问题能定位在 host 接口还是屏幕注册上。
