# 17-终端排序功能

> 状态：**讨论中**（2026-11-11）：用户提出需求，方案待确认，未实现。
> 最后更新：2026-11-11
> 目标：给节点管理终端与被动 IO 终端加明确的排序入口和排序档位。

## 一、目标

- 【用户想法·待确认】节点管理终端的节点顺序不明确，需要在界面左侧注册一个 AE2 按钮，新增排序功能。
- 【用户想法·待确认】被动 IO 终端同样需要排序入口。

## 二、方案

- 【Agent 建议·未确认】新增共享枚举 `FactorySortMode`，4 档：名称 / 模组 / 数量 / 状态。
- 【Agent 建议·未确认】两个终端的左侧 AE2 工具栏各加一个 `IconButton`，复用 AE2 现成图标
  `SORT_BY_NAME` / `SORT_BY_MOD` / `SORT_BY_AMOUNT` / `SORT_BY_INVENTORY_TWEAKS`，
  点击循环切档，tooltip 显示当前档与下一档。
- 【Agent 建议·未确认】排序在客户端模型里做，不改协议、不改存档；同值用名称兜底，避免每秒快照
  让卡片乱跳。
- 【Agent 建议·未确认】状态档按异常优先：失联 → 缺机 → 健康过期 → 未探测 → 输入堵塞 →
  运行 / 可输入 → 缺料 → 空闲 → 无规则；节点终端的 `FactoryStatus.Kind` 仍是包内可见，
  对外只加一个 `sortRank()`。
- 【Agent 建议·未确认】两个终端各自记住本次客户端会话的选择；切档后重建排版并夹紧滚动条。

## 三、待定

- 【待定】排序档位是否就这 4 档，是否还要「默认（服务端登记顺序）」档。
- 【待定】排序选择是否需要跨会话持久化（物品组件 / 客户端配置 / 服务端保存）。
- 【待定】被动 IO 终端除了节点块，是否也要排规则行与磁贴。
