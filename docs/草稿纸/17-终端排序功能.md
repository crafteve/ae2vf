# 17-终端排序功能

> 状态：**已定稿**（2026-11-11）：已实现并提交，可执行的设计约束同步到 ADR-041。
> 最后更新：2026-11-11
> 目标：两个终端加统一的排序入口、六档排序与升降序，偏好存物品组件。

## 一、已确认

- 【用户已确认】节点管理终端与被动 IO 终端都要排序入口，放界面左侧 AE2 工具栏；两个按钮：
  一个切档位、一个切升降序，形态与 AE2 终端一致。
- 【用户已确认】六档：名称（节点显示名）、ID（节点类型方块注册名 `typeBlockId`）、机器台数、
  IO 规则数、状态、距离玩家。
- 【用户已确认】默认档位＝名称；默认方向＝升序。升序＝从好到坏，降序＝从坏到好。
- 【用户已确认】状态档升序：运行 → 可输入 → 空闲 → 无规则 → 未知 → 仓库缺料 → 输入堵塞 →
  未探测 → 缺机 → 健康过期 → 失联。
- 【用户已确认】距离档：取离玩家最近的成员机器；非同维度视为无穷远；升序时同维度由近到远、
  其他维度在后；只在快照重建时（约 1 秒）用当时玩家位置重排，不每帧重排。
- 【用户已确认】同值兜底链：主键 → 名称 → 机器台数 → 节点 UUID，全部随方向按钮一起翻转。
- 【用户已确认】图标：名称 `SORT_BY_NAME`、ID `SORT_BY_MOD`、机器台数 `SORT_BY_AMOUNT`；
  状态、IO 规则数、距离三档自绘（走 `tools/gui/gen_textures.py`，规格 16×16、主色
  `#F2F2F2`、右下 1px 阴影 `#4D4D67`）；方向 `ARROW_UP` / `ARROW_DOWN`。
- 【用户已确认】档位循环顺序：名称 → ID → 机器台数 → IO 规则数 → 状态 → 距离。
- 【用户已确认】六档两个终端都上，共用同一套枚举与比较器。
- 【用户已确认】工具栏顺序：帮助 → 终端高度 → 档位 → 方向 →（被动 IO 再加视图切换）。
- 【用户已确认】中文名称按 Unicode 码位排序，不接拼音。
- 【用户已确认】排序偏好持久化到物品的 `ae2:exported_settings` 组件，跟列表 / 卡片视图同源，
  两个终端各自记住自己的选择；键为 `terminal_sort_mode` / `terminal_sort_direction`。
- 【用户已确认】终端物品已是 `stacksTo(1)`，不需要改堆叠。

## 二、实现记录（已落地）

- 节点状态由服务端 `NodeStatus` 唯一聚合（ADR-040），状态档只读展示档 `FactoryStatus.Kind`。
- 排序单位是节点；规则行与成员行不参与排序；列表 / 磁贴共用一套顺序。
- 排序在客户端模型 `rebuild()` 里做（过滤后、排版前）；重排后重建排版并夹紧滚动。
- 比较链只在 `FactorySortKey.comparator`，状态等级只在 `FactoryStatus.sortRank`。
- 排序枚举与设置键在 `menu`，比较器 / 按钮 / 上下文在 `client.screen`；方向复用 AE2 `SortDir`。
- 两个终端 host 都有 `IConfigManager`；一对 C2S / S2C 只用于写回偏好，`PROTOCOL_VERSION` → 33。
- 距离档玩家位置由屏幕在快照到达时取一次，传进模型，不进快照。
- 改名框 / 删除确认框打开时冻结行序（仅节点终端有模态框）。
- 自绘图标：状态＝三根阶梯条；IO 规则数＝三条规则行；距离＝两侧立柱 + 双向箭头。
