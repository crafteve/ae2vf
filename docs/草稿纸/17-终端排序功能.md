# 17-终端排序功能

> 状态：**讨论中**（2026-11-11）：档位、方向、兜底、持久化已确认，两个自绘图标在画，实现计划待写。
> 最后更新：2026-11-11
> 目标：两个终端加统一的排序入口、六档排序与升降序，偏好存物品组件。

## 一、已确认

- 【用户已确认】节点管理终端与被动 IO 终端都要排序入口，放界面左侧 AE2 工具栏；两个按钮：
  一个切档位、一个切升降序，形态与 AE2 终端一致。
- 【用户已确认】六档：名称（节点显示名）、ID（节点类型方块注册名 `typeBlockId`）、机器台数、
  IO 规则数、状态、距离玩家。
- 【用户已确认】默认档位＝名称；默认方向＝升序。升序＝从好到坏，降序＝从坏到好。
- 【用户已确认】状态档升序：运行 → 可输入 → 空闲 → 无规则 → 未知 → 仓库缺料 → 输入堵塞 →
  未探测 → 缺机 → 健康过期 → 失联。
- 【用户已确认】距离档：取离玩家最近的成员机器；非同维度视为无穷远；升序时同维度由近到远、
  其他维度在后；只在快照重建时（约 1 秒）用当时玩家位置重排，不每帧重排。
- 【用户已确认】同值兜底链：主键 → 名称 → 机器台数 → 节点 UUID，全部随方向按钮一起翻转。
- 【用户已确认】图标：名称 `SORT_BY_NAME`、ID `SORT_BY_MOD`、机器台数 `SORT_BY_AMOUNT`、
  状态 `SORT_BY_INVENTORY_TWEAKS`、距离与 IO 规则数自绘（走 `tools/gui/gen_textures.py`）；
  方向 `ARROW_UP` / `ARROW_DOWN`。
- 【用户已确认】工具栏顺序：帮助 → 终端高度 → 档位 → 方向 →（被动 IO 再加视图切换）。
- 【用户已确认】中文名称按 Unicode 码位排序，不接拼音。
- 【用户已确认】排序偏好持久化到物品的 `ae2:exported_settings` 组件，跟列表 / 卡片视图同源，
  两个终端各自记住自己的选择。
- 【用户已确认】终端物品已是 `stacksTo(1)`，不需要改堆叠。

## 二、方案（Agent 建议·未确认）

- 前提：节点状态由服务端 `NodeStatus` 唯一聚合（ADR-040，协议 32），状态档只读展示档
  （`FactoryStatus.Kind`），排序层不再自己判断状态。
- 排序单位是节点：节点终端一行＝一个节点，被动 IO 一块＝一个节点；规则行与成员行不参与
  排序（规则下标是动作身份，重排会让点击落到别的规则上），列表 / 磁贴两种视图共用一套顺序。
- 排序在客户端 model 的 `rebuild()` 里做：过滤之后、生成行 / 块之前；重排后重建排版并夹紧
  滚动。点击命中用当帧排版下标，展开 / 改名 / 删除用 `nodeId`，重排不会让动作串位。
- 排序枚举与设置键放 `menu`（服务端也要读），比较器与按钮放 `client.screen`；方向值复用 AE2
  的 `SortDir`。
- 两个终端 host 都要有 `IConfigManager`（节点终端目前没有）；新增排序设置包（C2S / S2C），
  `PROTOCOL_VERSION` 递增到 33。
- 距离档的玩家位置由屏幕取、传进模型，不进快照。
- 改名框 / 删除确认框打开时冻结当前顺序，避免误点。
- 自绘图标规格：16×16，主色 `#F2F2F2`、右下 1px 阴影 `#4D4D67`，与 AE2 `states.png` 图标同款；
  距离＝两侧立柱 + 双向箭头，IO 规则数＝三条规则行（行首小方块 + 长条）。
