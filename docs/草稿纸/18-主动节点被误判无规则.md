# 18-主动节点被误判无规则

> 状态：**讨论中**（2026-11-11）：现象与成因已确认，用户决定暂不视为 bug，留档备查。
> 最后更新：2026-11-11
> 目标：记录「只有样板、没有 IO 规则的主动合成节点显示无规则」的成因与潜在修法。

## 一、现象

- 节点只上传了样板、没配 IO 规则（主动合成的合法形态）时，两个终端都显示「无规则」；
  正在合成也显示不出「运行」。
- 影响：状态文字、灯色、搜索命中，以及排序功能里状态档的排序位置。

## 二、成因

- `MachineView.totalState()` 在 `ruleCount == 0` 时提前返回 `UNCONFIGURED`，排在
  `workState == WORKING → RUNNING` 的判断之前。
- `NodeStatusResolver` 的 UNCONFIGURED 判据只看 `ruleCount`（IO 规则数），不看样板数。
- `NodeView.configured()` 却是 `ruleCount > 0 || patternCount > 0`，两处口径不一致。

## 三、决定

- 【用户已确认】暂不视为 bug，先记录；修不修、什么时候修待定。

## 四、潜在修法（Agent 建议·未确认）

- `MachineView.totalState()` 去掉 `ruleCount == 0` 的提前返回，配置与否交给节点级判定。
- `NodeStatusResolver.resolve` 增 `patternCount` 参数，UNCONFIGURED 改成「规则 0 且样板 0」；
  `byNode` 改为从节点配置取（`FactoryTableSnapshots` 手里有 Factory，不用给机器表加字段）。
- 不动协议；改完在 ADR-040 补一句口径。
