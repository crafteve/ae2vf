# 14-节点终端与绑定杖

> 状态：讨论中
> 最后更新：2026-11-04
> 目标：定下节点管理终端的信息/按钮排布，以及它和绑定杖编辑态如何衔接。
>
> 2026-11-04 绑定方式已改为“绑定杖客户端草稿 + 完成时一次上传”，不再使用服务端会话与 60 秒过期；最新结论见 [15-节点数据层重构确认](15-节点数据层重构确认.md)。本文件保留早期讨论与终端排布。

## 【用户已确认】

- 节点管理终端与 IO 管理终端**分开**：节点终端只管节点、成员与节点级动作；IO 终端只管规则与供应器。（2026-11-04）
- 堆叠绑定采用**方案 A：粘性编辑态**；方案 B 留给后续多方块；方案 C 否定。（2026-11-04，详见 13）
- 先不做多方块，只做「一个节点挂多台单方块机器」；示例统一用熔炉 ×8。（2026-11-04）
- **倍增**是 provider 的设置：放入样板 A 后，开「倍增 ×2」就把样板按比例 ×2 报告给 AE；「智能倍增」按机器容量乘对应倍数。属于后续开发功能，但按钮需要保留。（2026-11-04）
- **复制 / 粘贴**属于 IO 终端：节点大卡片的机器行按钮复制该卡片配置，新无配置节点用粘贴按钮接收。（2026-11-04）
- 节点终端**不要 IO 跳转按钮**；IO 是独立终端。（2026-11-04）
- 节点终端**不要底部选中操作条**；把信息和按钮放进节点卡片列表里。（2026-11-04）
- 按钮要按 UX 分常用 / 不常用，做视觉美化，尽量一跳完成配置。（2026-11-04）
- **MC 的按钮不显式写文字**：按钮只用图标，名称、状态、当前档位放 tooltip 或信息行，靠图标、底色、位置表达。（2026-11-04）
- 节点卡片**不要左侧小三角**：点整张卡展开；堆叠的展开放在行尾对应动作位。（2026-11-04）
- **改名直接点节点名**，原位变输入框。（2026-11-04）
- **只有定位放在机器行**；删除、编辑、阻挡、倍增都归节点级，不占机器行。（2026-11-04）
- 节点级动作必须**常驻在节点行上，不展开也能看到、能点**；不能藏进展开区、hover 或右键。（2026-11-04）
- **编辑（+）= 编辑节点**；**阻挡、倍增 = 节点的 provider 配置**，和节点管理共用同一个终端；IO 已独立出去，节点终端不放 IO 按钮。（2026-11-04）
- **不是 ME 网络存储时节点不存在**；此时阻挡、倍增按钮应当灰显。（2026-11-04）
- 交互底线：1 跳完成、0 界面切换、按钮可见；按钮不写字，状态用底色/角标/tooltip。（2026-11-04）
- 节点行右侧分两组：**provider 组 = 阻挡 + 倍增 + 逐台/轮询切换**；**编辑（+）与删除（×）成组放最右**；按钮再小一档。（2026-11-04）
- 展开后的机器行只放**定位**；节点行不展开也要能看到全部节点级按钮。（2026-11-04）

## 【用户已推翻】

- （2026-11-04）方案 1 的「选中后底部固定操作条」：改为卡片内嵌信息与按钮。
- （2026-11-04）用 hover / 右键把按钮藏起来，来回避「一排按钮丑」：否定，按钮必须常驻可见。
- （2026-11-04）把节点级动作放进展开后的设置行：否定，不展开就看不到，不算节点级。
- （2026-11-04）把删除、改名放进机器行：否定，机器行只放定位；改名点节点名。
- （2026-11-04）只改间距 / 字号 / 卡片高度冒充「截然不同的设计」：否定，要连交互与控件形态一起改。
- （2026-11-04）自作主张增加或移动用户没有指定的动作：禁止，只有用户明确说的才做。

## 【Agent 建议·未确认】

### 动作集合

- 节点卡片上的 6 个动作：**定位、编辑、阻挡、倍增、改名、删除**；删除红色并二次确认。
- 阻挡、倍增是状态型按钮：按钮上直接显示当前值（阻挡 开/关、倍增 ×1/×2/智能），左键正向循环、右键反向，避免再开一个设置页。
- 样板、复制 / 粘贴在 IO 终端，不出现在节点终端。

### 三种卡片排布（待选）

1. **常驻卡片**：卡头 + 一行信息 + 两行按钮，每张卡约 66px，所有动作一跳直达，一屏约 4 个节点。
2. **展开卡片**：默认只有卡头，点开后在卡内长出信息、按钮与成员，展开卡约 100px；列表最干净，但操作要两跳。
3. **左右分栏卡片**：卡头 + 左侧信息 + 右侧 2×3 按钮，每张卡约 50px，一跳直达且一屏约 6 个节点；按钮偏小。

### 信息

- 卡头：图标 ×N、名字、成员台数、方块数、状态灯。
- 摘要：阻挡、主动/被动、样板数、规则数；维度/坐标/短 id/速率/最近搬运放 tooltip。
- 卡片自身承载操作，不再有“选中态”；hover 只做描边高亮。

### 与绑定杖的衔接

- 卡片上的「编辑」→ 关闭终端，发请求为该节点开编辑会话；主手必须持有机器绑定杖，否则动作栏提示。
- 世界里的蹲下右键与终端「编辑」是**同一个服务端会话对象**。
- 会话是粘性的：蹲下右键另一台机器 = 切换节点；蹲下右键空气 = 退出；登出、换维度、超时（建议 60 秒）自动清。
- 终端重新打开时读取会话，对应卡片标「编辑中」，按钮变为「退出编辑」。
- 编辑态手势沿用方案 A：右键加入、左键移除、Ctrl + 右键整片加入；目标必须与节点同维度且在距离内。
- 移除最后一台：节点有规则或样板时拒绝并提示去终端删除；没有则删节点并退出会话。

### 反馈

- 加入 / 移除成功或失败都走动作栏，失败必须带原因（已属于别的节点、不是有效机器、超距、机器库满）。
- 世界里整组方块画绿框，当前目标再亮一层；成功 / 失败给音效。
- 终端每 20 tick 拉一次表；编辑期间屏幕关闭，重开时拿到最新状态。
