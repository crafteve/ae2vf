# 04-产品定位与核心循环

> 状态：讨论中
> 最后更新：2026-10-31
> 标记：【用户已确认】/【用户想法·待确认】/【Agent 建议·未确认】/【用户已推翻】；技术判断归入 Agent 建议。
> 一句话：AE2 附属；无线管理机器的被动 IO 和主动样板下单；核心是服务器 tick 上的全局逻辑。

## 【用户已确认】

- AE2 附属，AE2 硬依赖；不做脱离 AE2 的独立版。
- 无线管理机器的被动 IO + 主动样板下单；对象是机器。
- 只需要一个 Machine 对象；Line 不再是必须的数据对象。
- Factory 对象保留，绑定 ME 网络；机器绑定杖把机器绑到该网络的 Factory。
- 全局逻辑绑在服务器 tick 上，不是方块实体。
- 需要一个 UI 管理机器、被动 IO、主动样板。
- 主动合成需要 ME 仓库 + CPU。

## 【用户想法·待确认】

- 主动合成采用虚拟生产，还是真实机器加工（喂机器 / 等加工 / 抽产物）。
- 无线范围：跨维度？距离限制？区块未加载怎么办？
- 一个网络一个 Factory。
- 终端形态 / 工具如何绑定网络。

## 【Agent 建议·未确认】

- Machine 是唯一配置对象；Factory 持有 `MachineLibrary`；Line 降为 UI 分组 / 视图。
- UI 一个工作台、两个模式：被动模式管 IO，主动模式管样板。
- 存储 ME-only，容器作为 ME 外部存储。

## 【用户已推翻】

- 主动 / 被动产线作为独立数据对象、一个主动线、popup 新建主动线。
- “UI 独立、AE2 可选”。
- 一人一个 Factory。

## 【Agent 建议·未确认】（技术判断）

- 服务器 tick + 无方块实体：区块未加载不能访问机器。
- 无线不等于强制加载；区块未加载时机器只能显示不可用。
