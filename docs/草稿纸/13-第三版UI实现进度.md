## 关键约束

- 内容视口：`x = leftPos + 4`、`y = topPos + 17`、宽 `167`（195 减左右各 4、减滚动条 20）、高 `rows × 18`。
- 块结构：机器行是机器大卡片顶部内缩 1px 的深色带（不再单独成卡）；机器行 20、规则行 20；无规则时整块只有机器行高；块间距 2。
- 拖入区：没有虚线新增行，整张机器大卡片都是拖拽目标（按视口裁剪）；行缝与规则之后的空白命中 `Kind.ADD`。
- 状态灯：`FactoryLamp` 3px（亮 / 本色 / 暗三列），只画在机器行；IO 卡片不画方向灯条，方向由 chip 表达。
- 规则行：图标凹槽 18（左缩进 3）+ 名字 + 方向 chip 11 + 面 chip 11 + 模式 chip 11 + 速率 38。
- 磁贴：77×34，两列，列间距 2，区内边距 2；第二行放三枚 chip 与速率；图标左缩进 2。
- 速率列只有 38px，FE 去掉「 FE」后缀，完整单位放 tooltip；0 速率用空闲灰，不跟块状态色。
- 高度：`AEConfig.getTerminalMargin()` 之后直接把**屏幕可用高度**传给 `TerminalStyle.getPossibleRows()`，不能提前减 header/bottom。
- 视图值非法或旧物品没有组件时回退 `LIST`；每个物品栈独立。
- 滚动：像素滚动，`maxScroll = max(0, contentHeight − 视口高)`；AE2 滚动条的 `setRange(min, max, page)` 三个参数不能写错。
- 内容区先于 `super.mouseClicked` 处理点击，否则原版容器界面会吞掉 chip 点击。
- AE2 终端行贴图中间自带槽位网格，内容区必须铺面板色盖掉。
