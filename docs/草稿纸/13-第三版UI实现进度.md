## 【用户已确认】

- （2026-11-03）**第二版终端删除**：合成/样板终端、左侧 IO 面板、样板管理面板、V2 菜单与专属网络包全部删除；V1 旧工作台保留为兜底。
- （2026-11-03）**终端物品右键不再有功能**：`FactoryTerminalItem` 不再实现 `IMenuItem`，右键不打开界面；快捷键仍用它判断玩家是否携带终端。
- （2026-11-03）**样板数据交给 AE2 原生管理**：`MachineNode` 继续实现 `PatternContainer`，样板仍在 `MachineProvider`；AE2 样板访问终端可按机器管理。
- （2026-11-03）**第三版采用 B 方案框架**：复用 AE2 `base_terminal` 边框与 36 个玩家背包槽，中间内容区自绘；不自绘 AE 库存列表。
- （2026-11-03）**左侧三个按钮**：`?` 指南、终端高度、列表/卡片视图；`?` 的 GuideME 逻辑后续再接。
- （2026-11-03）**右侧滚动条**：使用 AE2 风格滚动条。
- （2026-11-03）**高度存 AE 全局 `AEConfig`**：与 AE2 终端一致，不做每物品独立高度；会影响 AE2 自己的终端。

- （2026-11-03）视图切换走服务端权威：`FactoryPassiveIoViewC2S` 写组件，`FactoryPassiveIoViewS2C` 回确认；协议版本 24。
- （2026-11-03）`?` 暂用同图标占位按钮，点击空操作；等本模组 GuideME 页面确定后再接跳转。

## 关键约束

- 高度：`AEConfig.getTerminalMargin()` 之后直接把**屏幕可用高度**传给 `TerminalStyle.getPossibleRows()`；该方法内部再减 header/bottom，不能提前减，否则 `possibleRows` 为 0，行数永远被最小值兜底。
- 视图：值非法或旧物品没有组件时回退 `LIST`；每个物品栈独立。
- 滚动条：位置沿用 `base_terminal.json` 的 `scrollbar` 定义，内容宽度为滚动条让出约 20px；滚动位置不持久化。
- 左侧按钮：`AEBaseScreen` 自带帮助按钮在 `getHelpTopic() == null` 时会 `setVisibility(false)`，所以指南按钮不能只依赖自带按钮。
- 内容区：当前仍是占位，尚未接机器快照、搜索、分组、规则卡片或 JEI。
