## 关键约束

- 内容视口：`x = leftPos + 4`、`y = topPos + 17`、宽 `167`（195 减左右各 4、减滚动条 20）、高 `rows × 18`。
- 块结构：3px 状态竖线贯穿整块；机器行 20、规则行 20、虚线新增行 20；块间距 3。
- 规则行：方向色条 2 + 图标凹槽 18 + 名字（约 62px）+ 方向 chip 11 + 面 chip 11 + 模式 chip 11 + 速率 38。
- 磁贴：77×34，两列，列间距 4，区内边距 3；第二行放三枚 chip 与速率。
- 速率列只有 38px，FE 去掉「 FE」后缀，完整单位放 tooltip；0 速率用空闲灰，不跟块状态色。
- 高度：`AEConfig.getTerminalMargin()` 之后直接把**屏幕可用高度**传给 `TerminalStyle.getPossibleRows()`，不能提前减 header/bottom。
- 视图值非法或旧物品没有组件时回退 `LIST`；每个物品栈独立。
- 滚动：像素滚动，`maxScroll = max(0, contentHeight − 视口高)`；AE2 滚动条的 `setRange(min, max, page)` 三个参数不能写错。
- 内容区先于 `super.mouseClicked` 处理点击，否则原版容器界面会吞掉 chip 点击。
- AE2 终端行贴图中间自带槽位网格，内容区必须铺面板色盖掉。

## 2026-11-03 晚：界面回归修复

- **切高度重影**：`FactoryPassiveIoScreen.init` 先 `clearWidgets()` 再 `super.init()`。以前高度按钮直接再走一次 `init`，旧搜索框 / 工具栏按钮留在 `children` 里，旧位置的控件继续渲染，表现为「搜索机器…」重复多次、旧内容串到顶栏。
- **工作区描边**：只包自绘内容，不含左侧按钮、搜索框和右侧滚动条；内容视口再向内缩 1px 给亮边让位，描边框与搜索框之间留 4px 间距。边框改成「上 / 左 1px 亮边 + 下 / 右 1px 暗边 + 外侧 1px 半透明阴影」，参考 AE2 样板管理终端的槽位区。
- **搜索框**：改用 AE2 原生 `AETextField` 贴图（亮色边框 + 内凹阴影），和样板管理终端一致。
- **机器大卡片**：机器行改用深色 `machine_card`（白字），块体用 `row_card` 大卡片；列表规则行与磁贴都再套一层 `row_card`，形成「深色标题 + 浅色卡片」的层次。
- **状态条**：3px 状态竖线只画在机器行左侧，机器行以下把 3px 还给卡片，卡片可以铺到内容区最左边。
- **卡片间距**：磁贴列 / 行间距 2；列表规则行之间加 2px 缝隙（`ROW_GAP`），行本身是独立小卡片。
- **悬停高亮**：列表行用行矩形，磁贴用磁贴矩形；以前磁贴误用了列表行高，只亮卡片的一截（上半或下半）。chip 悬停只亮 chip 自己，且高亮垫在文字下面，不再由 `drawHover` 叠第二层。
- **取消选中模式**：左键卡片不做事；右键卡片直接删除；右键 chip 反向循环（面新增 `previousFace`，方向/模式两态反向与正向相同）。悬停卡片整张卡亮，悬停 chip 只有 chip 亮，右键跟随悬停对象走。
- **搜索框提示**：`FactorySearchEditBox` 在聚焦或有内容时把 hint 临时清空，光标和输入文字不会再和「搜索机器…」叠字。
- **字体颜色**：AE2 主题的 `textPrimary` 改纯黑、`textDim` / `statusIdle` 改中性灰、`textValue` 与 `modeExactText` 改纯黑、终端标题改纯黑；不再使用蓝黑。
- `./gradlew.bat build` 通过。
