# 05-UI 产品结构

> 状态：讨论中
> 最后更新：2026-10-31
> 标记：【用户已确认】/【用户想法·待确认】/【Agent 建议·未确认】/【用户已推翻】；技术判断归入 Agent 建议。
> 目标：定义工厂工作台的信息架构：机器中心，管理被动 IO 与主动样板。

## 【用户已确认】

- 需要一个 UI 管理机器、机器的被动 IO、主动样板。
- 机器是对象；当前方向不再为产线单独做一套界面。
- UI 手感需要接近 AE2，不再坚持完全独立的手写交互层。

## 【用户想法·待确认】

- UI 入口：终端物品右键 + `/idf gui`，还是只保留终端物品。
- v1 是否显示主动合成队列 / CPU 任务。
- 多人共享工厂的权限 UI 是否 v1。

## 【Agent 建议·未确认】

- 一个工作台、两个模式：被动模式（按视图分组，右侧 IO）、主动模式（有样板的机器，右侧样板）。
- 顶栏：绑定网络 / Factory、在线状态、仓库摘要、工具绑定状态。
- 左栏：机器列表 + 搜索 / 排序 + 状态徽标（PRESENT / UNLOADED / MISSING、IO 数、样板数）。
- 右栏：机器详情；被动只显示 IO，主动只显示样板与输入 / 输出预览。
- v1 只做：绑定、机器列表、被动 IO、样板添加 / 取出、顶栏状态。
- 视觉保留工厂主题；控件行为向 AE2 靠。

## 【用户已推翻】

- 主动 / 被动产线作为两条可新建的线；一个主动线 popup。

## 【Agent 建议·未确认】（技术判断）

- 当前手感差距主要来自 UI 基座（vanilla `AbstractContainerScreen` vs AE2 控件层），不是布局。
