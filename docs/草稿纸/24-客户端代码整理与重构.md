## 实现约定（用户授权设计）

【实现约定】`GuiLayerSpec` 层序：

| 层 | 值 | 用途 |
|---|---|---|
| WINDOW | 0 | 终端背景 |
| CHROME | 10 | 外框、标题、物品栏槽位底 |
| CHROME_ITEM | 11 | 物品栏图标 |
| CHROME_ITEM_DECORATION | 12 | 物品栏数量 / 耐久 |
| CARD | 20 | 卡片底 |
| CARD_HOVER | 21 | 卡片悬停 |
| CARD_ITEM | 22 | 卡片内物品图标 |
| CARD_ITEM_DECORATION | 23 | 卡片内数量 / 耐久 |
| CARD_CONTENT | 24 | 卡片内文字、按钮、chip |
| WIDGET | 30 | 搜索框、滚动条、工具栏按钮 |
| OVERLAY | 40 | 确认框等浮层 |
| DRAG | 50 | 拖拽幽灵 |
| TOOLTIP | 60 | tooltip |

物品图标用 pose 补偿原版 `renderItem` 的 150 偏移，落到卡片层。

【实现约定】`SearchKey`：`name、iconId、status、dimension、pos、machineCount、ruleCount、distance、extra`；`extra` 放 IO 规则资源名等附加文本。

【实现约定】`SortKey`：`name、id、machineCount、ruleCount、statusRank、distance`。

【实现约定】`TerminalSource`：`request()`、`acceptFullPage(pageIndex, pageCount, page)`、`acceptDiff(diff)`、`table()`、`revision()`、`reset()`。

【实现约定】`ViewTableSink`：`containerId()`、`acceptFullPage(...)`、`acceptDiff(...)`。

【实现约定】`TerminalModel` 字段：`source、query、sortMode、sortDirection、scrollOffset、playerDimension、playerPosition、rows`；方法：`rows、setQuery、setSort、setScrollOffset、setPlayerContext、refresh、statusKind`；抽象：`buildRows、searchKey、sortKey`。

【实现约定】`Probe` 两个类删除；需要日志时直接用 `LOGGER`。

## 关键约束

- `client.*` 只在客户端加载，服务端类不得引用。
- `client.network` 只做“收到包 → 投给屏幕/绑定杖”，不做业务判断。
- 两个终端共用外壳、数据源、绘制原件与文案；业务聚合已在服务端视图表完成。
- 迁移期间旧类可短暂共存，不做兼容层；每批结束删除旧类。
